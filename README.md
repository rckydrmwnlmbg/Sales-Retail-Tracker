# Ricky Sales Tracker

Ricky Sales Tracker adalah sistem operasi pertumbuhan penjualan (Personal Sales Growth Operating System) yang dirancang khusus untuk tenaga penjualan pemasaran dan retail. Aplikasi ini membantu mengelola prospek, melacak transaksi, dan menganalisis kinerja penjualan secara waktu nyata (real-time).

## Fitur Utama

- **Pelacakan Penjualan (Sales Tracking)**
  Catat setiap aktivitas penjualan, prospek, pertanyaan pelanggan, dan transaksi yang berhasil maupun yang hilang secara sistematis.

- **Dasbor Analitik (Analytics Dashboard)**
  Visualisasi data metrik yang komprehensif, menampilkan tren pendapatan bulanan, mingguan, dan harian. Fitur analitik dilengkapi dengan laporan tren penjualan, konversi, *peak hour heatmap* (jam sibuk), riwayat menang-kalah (*win/loss analysis*), hingga analisis produk.

- **AI Coach (Asisten Pelatih AI)**
  Dapatkan ulasan berkinerja (Performance Review), analisis celah pengetahuan (Knowledge Gap Analysis), dan wawasan panduan langsung (Insights) mengenai aktivitas penjualan dan cara meningkatkan konversi berdasarkan data performa Anda menggunakan integrasi kecerdasan buatan (GenAI) melalui OpenRouter.

- **Profil & Manajemen Waktu (Profile & Shift Management)**
  Pengaturan profil pengguna, target bulanan, serta pelacakan jam shift atau *clock in* dan *clock out*.

## Integrasi Kecerdasan Buatan (AI)
Aplikasi ini mendukung otomatisasi dan analisis menggunakan AI. Anda bisa menyematkan OpenRouter API Key pada menu profil untuk menggunakan layanan fitur *AI Coach*.

## Dibangun Menggunakan
- **Kotlin** & **Jetpack Compose** untuk pengembangan User Interface secara native.
- Arsitektur **MVVM** dengan StateFlow.
- **Room Database** untuk pengelolaan data offline.
